# نظام كربون لإدارة المشاريع

تطبيق ويب عربي لإدارة مشاريع كربون: المشاريع وأقسامها، بنود BOQ ونسب إنجازها، دورة طلب المواد من الموقع حتى أمر الشراء، البيتي كاش، والأعمال الإضافية مع موافقة العميل. يعمل على GitHub Pages ويحفظ البيانات في Supabase.

## دورة طلب المواد
مهندس الموقع يطلب ← رئيس القسم يوافق ← المشتريات تسجل عروض الأسعار ← المالية تدقق الميزانية وبند BOQ ← المدير العام يعتمد ← المشتريات تصدر PO (دفعة مقدمة أو آجل 30 يوم).

كل خطوة محمية في قاعدة البيانات: ما يقدر أحد يعتمد خطوة مو من دوره.

## الأدوار
| الدور | يقدر |
|---|---|
| مدير النظام | يدير المستخدمين والمشاريع ويشوف كل شي (بدون اعتماد مشتريات) |
| صاحب الشركة | يشوف كل شي، يضيف المشاريع، يدير المستخدمين |
| المدير العام | نفس صاحب الشركة + الاعتماد النهائي للشراء والبيتي كاش |
| رئيس قسم | يعتمد طلبات قسمه (أو كل الأقسام إذا بدون قسم) ويحدّث الإنجاز |
| مهندس موقع | يرفع طلبات المواد والبيتي كاش والأعمال الإضافية ويحدّث الإنجاز |
| المشتريات | عروض الأسعار وإصدار أوامر الشراء |
| المالية | تدقيق الميزانية |

أول حساب يصير "مدير النظام". بعدها مدير النظام يضيف الموظفين من صفحة المستخدمين (ما فيه تسجيل ذاتي). إضافة الموظفين تتم عبر Edge Function `manage-user`.

## الترقيم
كل المستندات تبدأ بـ CEC (Carbon Engineering Consultancy) ثم النوع ثم السنة والشهر ثم رقم تسلسلي يبدأ من 1 كل شهر: `CEC-PRJ-2611-001` مشروع، `CEC-MR-2611-0001` طلب مواد، `CEC-PO-2611-0001` أمر شراء، `CEC-PC-2611-0001` بيتي كاش، `CEC-VO-2611-001` عمل إضافي.

## قراءة BOQ والمدد
عند إضافة مشروع جديد ترفع ملف BOQ، والنظام يقرأ البنود ويوزع كل بند على القسم المسؤول ويعطي كل بند تاريخ بداية ونهاية حسب مدة المشروع وقيمة البند وترتيب الأعمال (تصميم، إنشاءات، منجرة، فيت أوت، تسليم). كل شي قابل للتعديل قبل الحفظ.
- ملفات Excel و CSV و PDF النصي واللصق تنقرأ داخل البرنامج فوراً (`boq-engine.js`) بدون أي تكلفة.
- PDF المصوّر أو الصورة ينقرأ داخل البرنامج أيضاً (`boq-ocr.js`): خطوط الجدول تحدد الصفوف والأعمدة، وTesseract يقرأ الكلام عربي وإنجليزي. ياخذ حوالي 20 ثانية للصفحة وبدون تكلفة.
- لو ما قدر يقرأ أي بند، يروح الملف للذكاء الاصطناعي (Claude) عبر Edge Function `analyze-boq` إذا كان سر `ANTHROPIC_API_KEY` مضاف في Supabase.
- في صفحة المشروع، تبويب الجدول الزمني يعرض كل بند على المخطط. مهندس الموقع ورئيس القسم (بنود قسمه) والإدارة يعدّلون المدد، والمدير العام يعتمد الجدول.

## التشغيل
1. في Supabase: افتح SQL Editor والصق محتوى `supabase/setup.sql` واضغط Run (مرة وحدة فقط).
2. في Supabase: Authentication ← URL Configuration، حط رابط الموقع في Site URL.
3. حدّث `config.js` برابط المشروع والـ Publishable key.
4. في GitHub: Settings ← Pages ← Deploy from a branch ← `main` / root.

## الملفات
- `index.html`, `app.js`, `styles.css`, `config.js`: التطبيق.
- `supabase/setup.sql`: الجداول والصلاحيات وبيانات مشروع الحاضنات (BOQ والجدول الزمني).
- `supabase/migrations/`: نفس قاعدة البيانات مقسمة على ملفات (من 004 فما فوق تُطبّق بعد setup.sql).
- `supabase/functions/`: `manage-user` لإدارة الموظفين و`analyze-boq` للتحليل الذكي.
- `prototype/`: النموذج التجريبي الأول ببيانات أمثلة.
